# CRiEYA Landing Page

A responsive single-page landing page concept for CRiEYA, using the supplied logo and a palette inspired by its purple, orange, and green accents.

## Run locally
Open `index.html` in a browser. No build step is required.

## Deploy to Vercel
1. Extract the ZIP.
2. Import the folder into a Git repository, or drag the folder into a supported static deployment workflow.
3. Deploy as a static site. No framework or build command is required; the output directory is the project root.

## Files
- `index.html` — page content and semantic structure
- `styles.css` — responsive layout, color system, hover states, reduced-motion support
- `script.js` — mobile navigation, reveal-on-scroll effects, dynamic footer year
- `assets/crieya-logo.png` — supplied logo

## Before publishing
Confirm the current contact email, application process, funding figures, eligibility requirements, and any official social links with CRiEYA. This concept intentionally links to the official CRiEYA overview and supplied PDF rather than inventing a contact address.
